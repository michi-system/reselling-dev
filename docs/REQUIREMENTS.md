# 要件と優先順位

最終更新: 2026-02-10

## 絶対条件
1. 修正しやすい構造を維持する
2. 最低限使えるレベルで確実に動作する

## 優先順位
1. 精度: 誤採用を最小化する
2. 規約順守: API利用条件に反しないガードレールを実装する
3. 保守性: ルール変更の影響範囲が明確
4. 速度: 後回し (壊さない範囲で改善)

## MVPスコープ
- 手動登録された仕入れ商品と販売候補を比較
- 同一商品スコアリング
- 付属品/部品/カバー誤ヒット除外
- 利益率計算
- `auto_accept/human_review/reject` 判定
- 判定理由の保存
- コンプライアンス判定のトレース保存

## 非スコープ (次フェーズ)
- 実API連携ジョブの本番運用
- 機械学習モデル学習パイプライン
- ダッシュボードの高度可視化
